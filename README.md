## Featured Projects

### [Username Checker](https://github.com/Vini90fs/username-checker) — Python
OSINT command-line tool that checks whether a username exists on public platforms.
- **Per-platform checks:** public APIs (GitHub, Bluesky, Twitch) and HTML heuristics (Pinterest, Telegram)
- **False-positive handling:** an HTTP 200 is never treated as proof; sites that block requests become "manual check" links
- **Extensible design:** `main.py` · `checker.py` · `sites.py`

### [Dealership](https://github.com/Vini90fs/Dealership) — C
Terminal-based vehicle registration system for a car dealership.
- **Modular code:** `veiculo`, `arquivo` and `main`, built around a custom `struct`
- **Validation:** license plate (old and Mercosul formats) and 17-character VIN, no duplicates
- **Persistence:** delimited text file

### [Hotel Management](https://github.com/Vini90fs/hotel-management-system-c) — C
Hotel management system with file-based persistence.
- **Five modules:** guests, rooms, stays, employees and loyalty program
- **Persistence:** `fopen` / `fread` / `fwrite`
